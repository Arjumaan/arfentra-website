## 🏛️ Overview

This repository contains the production website for **Arfentra Private Limited**, engineered from the ground up matching the **Imperial Tech & Sovereign Capital** design specification from Stitch.

The site is built with a high-performance stack:
- **Vite 5** + **TypeScript** + **Tailwind CSS**
- **Three.js (r160)** WebGL Interactive 3D Autonomous Agent Network Core
- **Glassmorphic Wine & Champagne** Luxury Theme
- **Fully Responsive Architecture** with touch-optimized mobile drawer and persistent bottom quick-navigation bar
- **Interactive Consultation Booking Modal** with live form validation & direct contact triggers
- **100% Local Self-Contained Assets** (No external CDN dependencies for images, logos, or 3D badge sprites)

## 🚀 Quick Start

### 1. Installation
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Runs at `http://localhost:3000` with instant Hot Module Replacement (HMR).

### 3. Build for Production
```bash
npm run build
```
Generates a static, deployment-ready bundle in `./dist` configured with relative paths (`./`) so it runs seamlessly on Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any web server / CDN.

### 4. Preview Production Build
```bash
npm run preview
```
